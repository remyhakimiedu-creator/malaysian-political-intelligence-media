# research/

Cited, neutral **research briefs** — the factual foundation for all analysis and Threads content.

| Folder | Covers |
|---|---|
| `malaysia-politics/` | Parties, coalitions, Parliament, elections, state politics, courts, integrity cases |
| `public-finance/` | Federal Budget, revenue, expenditure, deficit, debt, subsidies, taxes |
| `economy/` | GDP, inflation, OPR, wages, jobs, trade, investment, cost of living |
| `geopolitics/` | Foreign policy, ASEAN, South China Sea, US–China, bilateral relations |
| `public-policy/` | Education, health, housing, transport, digital, environment and other sector policies |

**Created by:** `malaysian-political-research` (and the research steps of the analysis Skills).
**File name:** `YYYY-MM-DD-topic-slug.md` · **Template:** `templates/research-brief.md`

Rules
- Every substantive statement labelled ([FACT], [REPORTED], [CLAIM], [UNVERIFIED]…) and cited.
- Time-sensitive facts carry an "as of" date.
- Log every source in `sources/source-log.md`.
- Briefs are internal working documents — not for publishing as-is.
