# analysis/

Interpretation built on verified research: causes, incentives, implications, trade-offs and scenarios. Facts and analysis are kept visibly separate.

| Folder | Skill |
|---|---|
| `political/` | `political-analysis` |
| `public-finance/` | `public-finance-analysis` (also covers economy and costing of policies) |
| `geopolitical/` | `geopolitical-analysis` |

**File name:** `YYYY-MM-DD-topic-slug.md` · **Template:** `templates/analysis.md`

Rules
- Start from a brief in `research/` — link it in the "Based on" line.
- Interpretation labelled [ANALYSIS] with reasoning shown; all major sides steelmanned.
- Scenarios state assumptions and indicators — never forecasts presented as fact.
- Internal working documents — not for publishing as-is.
