# fact-checks/

Fact-check reports from `fact-checking-editor`, plus correction records.

**File name:** `FC-YYYY-MM-DD-NN-topic-slug.md` (NN matches the draft) · **Template:** `templates/fact-check-report.md`

Verdicts: **PASS** (ready for owner decision — not approval) · **REVISE** (fixable issues) · **FAIL** (false/unverifiable core claim or high legal risk).
