# sources/

The project's record of every source used.

- `source-log.md` — one row per source: ID, name, title, publish date, URL, access date, reliability grade (A–D), where it was used, caveats.

Reliability grades: **A** primary official record · **B** international institution / reputable research · **C** established media · **D** social media / press statements (leads only).

Rules
- Add a row whenever a brief, analysis, draft or fact-check cites a new source.
- Re-check time-sensitive sources (figures, office-holders, laws) before reuse.
- Do not store copyrighted full texts, leaked documents or personal data of private individuals — store citations and links.
