# published-posts/

Archive of posts the **owner** has published manually on Threads.

- Claude never publishes and never moves a file here on its own.
- When the owner says a post is live, Claude may (on request) move the approved file here and fill in `published_url` and the publish date.
- Keep the published text exactly as posted — do not edit after publishing.

## Corrections
If an error is found after publishing:
1. Run `fact-checking-editor` and save the finding in `fact-checks/`.
2. Claude drafts a correction post in `threads-drafts/` (same approval process).
3. Add a "Correction" note with date and link to the original file here.
